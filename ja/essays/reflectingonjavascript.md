*入り口は親しみやすく、使いこなすには奥が深い*

いくつかの言語を学んできた私も、JavaScript を始めたときは初心者でした。計算、変数の宣言、値の出力といった基本から確認する必要がありましたが、進めるうちに Java などの学習経験を生かせる部分も見えてきました。

特に印象に残ったのは、関数を値として扱える「第一級関数」という考え方です。関数を変数に代入したり、引数として渡したりできることは、処理の組み立て方を考えるうえで新しい視点になりました。

## 書き方の違いと ES6

従来の書き方に加え、ES6 の構文を学ぶと、最初は覚えることが増えたように感じました。一方で、アロー関数のように、意図を短く表せる記法には便利さを感じています。関数を変数に代入して使う流れも、慣れると読みやすくなりました。

ソフトウェア工学の観点では、読みやすさと使いやすさを両立できる点が魅力です。C++、Python、Java で学んだ考え方を足がかりにしながら、JavaScript ならではの特徴を少しずつ理解できました。

## 制限時間のある WOD で学ぶ

授業の WOD（制限時間内に取り組むプログラミング演習）は、かなり緊張する課題でした。時間内に終わらないかもしれない、正しく動かないかもしれないという不安があり、完成できるかどうかが評価を大きく左右します。挑戦する前に内容を十分に理解しておく必要がありました。

その厳しさは、練習を重ねる動機にもなります。どこを改善すれば速く書けるか、より短く、わかりやすく表現できるかを考えるようになりました。正しいコードを書く力に加え、限られた時間でそれを形にする力も問われるからです。

練習の過程で新しい発見があることは楽しく、WOD は JavaScript を身につける有効な機会だったと感じています。ただし、その効果を生かすためには、事前の準備と振り返りが欠かせません。
